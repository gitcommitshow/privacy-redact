# Examples

Hosts that call the privacy-redact library, the browser components, or (when they exist) the CLI and MCP wrapper. Each one has its own server and its own frontend. The core does not take their branding.

Import the library entry and call it. Do not copy detectors into the example. Improvements in the library then show up the next time the example runs.

## Playground

A small host that links `privacy-redact` and shows each call: text redaction, scan choices, transcripts, boxes, metadata, redaction styles, and the review screen. Every section runs live and has the sample a new project can paste.

See [playground/](playground/README.md).
